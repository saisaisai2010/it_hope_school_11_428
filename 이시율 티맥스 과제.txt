장르 : 타워 디펜스(판타지물)
구현 방법: html

게임 한줄 설명 : 몰려오는 몬스터들한테서  다양한 타워를 쌓고 강화하면서 성을 지키는 게임 

핵심 플레이:
	 1. 타워 배치
	 2. 타워 강화
	 3. 골드 횟득
	 4. 다음 웨이브 준비
	 5. 몰려오는 몬스터들 처치
	 6. 어떤 몬스터들이 오는지 확인
게임 규칙:
	1. 성벽이 무너지면(피가 0이되면) 게임 오버
	2. 타워 설치 갯수는 9개로 지정
	3. 골드로 타워을 사고 배치
	4. 모든 웨이브 달성 할시 게임 클리어
	5. 1웨이브마다 포탈에서나오는 모든 몬스터들을 처치시 웨이브 클리어
	6. 몬스터를 처치시 골드를 획득 
	7. 타워의 사정거리안에 몬스터가 들어오면 적을 자동 공력
	8. 맵에서 지정된 위치에서만 타워 설치 가능
	9. 각 타입별 타워마다 3개 설치 가능 	
	10. 1웨이브 마다 몬스터가 10마리 등장(웨이브가 올라갈 수록 1웨이브 10마리 2웨이브는 20마리 느낌으로 증가)
	11. 몬스터 한마리 처치시 4골드 획득. 
	12. 각 타입별 타워마다 최대 설치 수는 3개로 지정(예외로 성직자 타워는 하나 설치 가능)
	13. 1웨이브 클리어 마다 총 골드 120 획득 
	*14. 게임 시작 후 전투 중 ESC를 누르면 돌아기 버튼과 리섯 버튼 추가(ESC를 누르는 순간 게임도 멈추게)*

		   5. 마법사 타워: 설치 비용 190원/공격력 9정도 공속 3초정도 사정거리는 골렘과 비슷하게(원거리 공격 타워, 공격 모양은 범위 공격)

UI 상태 : 게임 메인 메뉴 바탕화면을 왕국 성이 보이도록. 게임 시작 버튼은 가운데에 낳두고 나머지 설정(음향. 등등)들을 게임 시작 버튼 아래 배치. 게임 시작을 누르면 스테이지 1 이라고 버튼이 보이고 나머지 스테이지 들은 전부 ??로 배치. 스테이지 1을 누르면 메인 게임화면으로 이동하고 게임 시작. 전체적인UI는 중세시대적인 UI이로. 인 게임 화면 : 몬스터들을 머리위에 체력바 표시.보스 등장시 보스바 하단 가운데 생성. 타워 공격 모션을 변경(궁수는 화살, 전사는 그대로, 성직자는 빛 효과, 골렘은 내려찍기 모션, 마법사는 파이볼로)

조작법 : 마우스로 메인 화면 클릭하고 게임 시작 -> 게임 시작시 상점을 열고 돈이 잇는데로 타워 구매 -> 2번째 방식을 반복하며 타워 강화하기 -> 게임 클리어시 로비로 이동

스타일 에셋 : 보스몬스터가 나올때마다 웅장한 소리 추가, 타워 공격소리 추가, 게임 클리어시 신나는 노래(짥게) 추가, 몬스터를 떄릴시 조그만한쪽득한 소리 추가

스킬 : 게임 밸런스 맞춤 스킬(ai스스로 게임을 돌려보고 밸런스가 안맞는 부분이 있으면 스스로 고치고 사용자한테 무엇을 고치었는지 알려줌)
