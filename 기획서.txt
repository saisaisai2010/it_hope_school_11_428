계기: 친구들과 리듬게임으로 내기하던 생각이나서 이 주제를 선정하게 되었습니다.

게게임 이름:네온 펄스


게임 방식
 -5개 레인:화살표 위 아래 왼쪽 오른쪽/스페이스바
 -화살표가 위에서 아래로 내려와 판정선에 도달하는 순간 해당 키 입력
 -판정 시스템은 PERFECT / GOOD / OK / MISS 4단계로
 -콤비 기능 추가하고 연속 성공 시 증가, 실패 시 0으로 리셋, 최대 콤보 기록
 -정확도 추가하고 %기록
 -잔잔한 곡(느림)과 신나는 곡(빠름, 타격음 포함) 2종 중 선택
 -화살표 타이밍은 음악에서 그대로 파생
 -EASY / NORMAL / HARD 3단계[속도가 아니라 화살표 개수(밀도)로 난이도 차이]
 -진행 흐름은, 시작 화면(곡 선택·난이도) → START → 카운트다운 → 리드인(화살표 미리 하강) → 리드인 종료와 동시에 음악   시작 → 플레이      → 결과 화면(또는 실패 화면) → RETRY 또는 홈으로 이동
 - UI컬러는 다크 네이비 + 네온 컬러로
 -게임중 진행률 바 생성
